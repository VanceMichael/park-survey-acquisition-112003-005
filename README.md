# 保护区联合评估资料

本地演练资料使用虚构的实物、机构和记录编号。经营单据存放于 `data/`，包括 `requests.json`、`permits.json`、`receipts.json`。来源原件在提供时由资料端送出。

## 资料约定

授权用接收单位、用途、保护区、季节、材料能力、有效轮次的交集。能力分别为 observation、coordinate、crosswalk。即便所在保护区允许坐标，附带旧卡把相关保护区的位置串出来也需要对卡作用域重新检查。样点编码和盲样号属于不同命名域。领用范围按授权号查；410 表示停止发放，404 表示资料尚未交来。收条以包成员为粒度。

根路径列出资料入口。各路径每次请求依次返回该路径的演练响应，最后一条响应保持不变。不同路径有各自的请求计数。重启资料端从首条响应开始。路径清单中的链接相对同一服务。非演练路由的原件对应 `originals/` 下同名路径，经营单据也可以从 `/data/文件名.json` 直接领取。

## 运行资料端

运行依赖为 Python 3.11 标准库。

```sh
python3 source_service.py --port 8040
```

以下命令核对本地资料服务和交互。

```sh
python3 -m unittest discover -s tests -v
```
